# worCat

worCat is a cat-themed Web PWA that brings calendar planning, personal ledger tracking, schedules, and work organization into one place.

## Core Features

- Calendar overview and daily summaries
- Income and expense tracking
- Schedule planning
- Work log and task tracking
- PWA installation support
- Multi-language interface
